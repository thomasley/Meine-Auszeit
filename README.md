# Meine Auszeit

Kostenlose iPod-Entspannungs-App für GitHub Pages. Die eigenständige index.html enthält Gestaltung, Menüsteuerung und die unveränderte kurze Norddeich-Hörprobe aus dem ursprünglichen Prototyp.

## Bedienung

- Im Kreis über das Rad streichen oder mit ◀◀ / ▶▶ auswählen.
- OK bestätigt, MENU geht zurück. Menüpunkte sind direkt antippbar.
- ▶Ⅱ öffnet die Wiedergabe und startet bzw. pausiert dort die Hörprobe.
- Während der Wiedergabe springen ◀◀ / ▶▶ zehn Sekunden zurück bzw. vor.
- Einstellungen und bis zu 50 beendete Hörproben mit Bewertung werden lokal im Browser gespeichert.

## Aktueller Aufnahmebestand

Verfügbar ist eine kurze Original-Hörprobe aus Norddeich. Sie ist keine vollständige 5-Minuten-Sitzung. Vollständige Aufnahmen für die wählbaren Orte, Stimmungen und Zeiten (5, 10, 15, 20 Minuten) fehlen noch und werden in der App ausdrücklich als fehlend gekennzeichnet. Es wird keine andere oder synthetische Stimme eingesetzt.

## Hosting

GitHub Pages: main, / (root). Kein Server und keine kostenpflichtigen Dienste erforderlich.
